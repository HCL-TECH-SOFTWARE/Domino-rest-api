# OData

## Overview

[OData](https://www.odata.org/) or *Open Data Protocol* lets compliant software, such as Excel on Windows, Salesforce, Power BI, read and potentially write REST data.

OData doesn't use [JSON Schema](https://json-schema.org/) but its own definition format, which is a mix on JSON, XML, and dot-notation. Testing has been done with Salesforce and Microsoft Excel. Kindly share details on what you are using.
